OLIVEIRA FROTA — FIREBASE JÁ CONFIGURADO

Os dados do aplicativo Web já foram inseridos em firebase-config.js.

FALTA SOMENTE ATIVAR OS SERVIÇOS NO FIREBASE:

1. Clique em "Continuar no console".

2. ATIVAR LOGIN:
   Firebase Console > Segurança / Authentication > Começar
   > Sign-in method > Email/Password
   > Ativar > Salvar.

3. CRIAR USUÁRIO:
   Authentication > Users / Usuários > Add user
   Crie o e-mail e a senha que serão usados no Oliveira Frota.
   Não coloque essa senha nos arquivos do GitHub.

4. CRIAR FIRESTORE:
   Firebase Console > Firestore Database > Create database
   Escolha Production mode.
   Mantenha o banco (default).
   Escolha uma região adequada.

5. PUBLICAR AS REGRAS:
   Firestore Database > Rules
   Apague o conteúdo atual.
   Copie todo o conteúdo do arquivo firestore.rules deste pacote.
   Clique em Publish / Publicar.

6. PUBLICAR O SITE:
   Envie todo o conteúdo deste pacote ao repositório GitHub
   OliveiraConstrucao/oliveira-frota, substituindo os arquivos existentes.

7. TESTAR:
   Abra o app > Dados > Firebase.
   Entre com o usuário criado no Authentication.
   Toque em "Sincronizar agora".

IMPORTANTE:
- O app continua funcionando offline.
- Quando a internet volta, as alterações pendentes são sincronizadas.
- A senha do usuário não é gravada no código do site.
- Faça "Exportar backup" antes da primeira sincronização da base que já contém dados.
